# TruckModel MPC Studio 2.9.3

2.9.3 是融合文档与参考实现的严谨化版本，取代 2.9.2 作为新集成的基线。依据是六份
独立审查（Claude Opus 5.5 max 与 GPT-5.6 sol max 交叉），并由 GPT-5.6 sol max 分上下
两半做多轮终审，逐轮修复，直到两半都确认没有阻断或高等级问题。

## 一处物理结论被纠正

- 本仓库默认参数下，稳态转弯时卡车后轴侧偏角是挂车轴的 1.736 倍（与车速无关）。
  旧文档的前提"卡车后轴近似纯滚动"不成立，因此 \(b_{r2}\) 与 \(r_2\) **反号**：
  \(U=12\) m/s 时 \(b_{r2}\approx-0.31\,r_2\)，旧文档写的是 \(+0.42\,r_2\)。
  docs/3 第 5.5 节给出由 (K8) 稳态推出的完整增益 (F6c)，新测试
  `testTrailerYawResidualOpposesTrailerYawRate` 用 K27 被控对象核对。
- 简化模型 (F7) 的时间常数只属于 \(\alpha_{1r}\equiv0\) 的假设；(K27) 在 17.55 m/s
  以上开环不稳定。

## 参考实现

以下改动都服务于一个可证明的性质：延迟滤波器与"在细化网格上逐时刻准时融合"的
EKF 执行相同的运算序列（docs/3 第 9.8 节）。

- 未 `reset` 就 `predict` 改为抛 `std::logic_error`，不再静默以 \(\phi=0\) 自启。
- `predict` 时间倒退抛 `std::invalid_argument`；同一时刻的第二个样本不再改写已传播
  帧的输入（demo 的自适应车速会发这种样本），只用于重算依赖最新输入的输出字段
  （\(\dot\phi\)、`truckYawResidual` 等）。
- 动力学模型的调度车速改为样本车速的纯函数（量化到 `modelRefreshSpeedStep`），
  重推回访旧区间时重建出完全相同的矩阵；缓存命中与否（包括跨 `reset`）不再影响结果。
- 每次传播之后对 \(P\) 做对称平均。
- 亚帧扫描先在临时切分帧上做马氏门限判定，接受后才插入历史；被拒的扫描不再留下
  切分帧。`update` 插帧后执行 `maximumFrames` 上限。
- 更新增加硬年龄检查：早于最新帧 − `historyHorizon` 的扫描判 `staleBeyondWindow`
  （修补时间大跳后的漏洞）。
- `coastingProcessNoiseScale`、`maximumFrames`、`snapToNearestFrame` 经
  `ArticulationEstimatorConfig` 暴露并校验；`coasting` 直接由开环条件判定；
  新增 `hasAcceptedMeasurement`；三个初始方差改为精确的 \((2°)^2\)。
- `DelayedEkf::reset` 校验协方差有限、对称、对角非负。

## 文档（docs/3）

- 补齐所有跳步推导：一般情形的 Van Loan 闭式与交叉项、\(P_{10}\) 的来源、F19 的块矩阵
  推导与分段复合、Joseph 误差传播、误拒率、可观行列式与 \(a_{31}\)、时延 RMS 等。
- 纠正多处表述：`arrivalGap` 是滤波器时钟上距上次接受的间隔，不是墙钟链路健康；
  "固定区间平滑"改为"细化网格上的准时滤波"；1° 安装偏差造成的 2.14°/s 只是瞬态上限。
- 规范补全：生命周期、全部数值容差、结局码的计数与消费戳规则、trim 与窗口伪代码、
  步长与车速契约、矩阵指数常数、更新开销、同拍顺序、`ArticulationEstimate` 逐字段表、
  会影响实测数字的 demo 约定（按到达顺序投递约 13% 扫描被判乱序、扫描戳落在网格上、
  从真值起步等）。
- 情况 B（没有扫描时间戳）改写为独立的第 18 章：严格的一阶 LMMSE 更新、公共偏移的
  可观性条件、五类方案、网格重建与原型验证数据（`tools/case_b_probe.cpp`）、决策树、
  感知团队确认清单。未同步的源时间戳只恢复顺序与相对间隔，绝对偏移仍需最小时延、
  PPS 或标定等锚点。周期未知时的冲突判据改为对全部允许斜率的联合可行性检验 (F35a)，
  前提是扫描相位抖动为零或有硬上界（有上界时按上界放宽）：原型实测先验正确时从不
  报警，先验偏 20 ms 时判 99% 以上的扫描不可行；原型在冲突后继续运行只是敏感性实验，
  生产实现必须停用或降级。当前扫描时刻的可行区间按联合可行域求 (F35b)，不再在单一
  斜率上取（那样有 9.8% / 36.3% 的扫描宽度为负）。原型 B4 的"单斜率端点加 \(w^2/3\)"
  被明确为保守近似；按 (F35b) 取中点、\(w^2/12\) 的诊断行戳误差减半，角度精度与 B4
  几乎相同。
- 终审补充：非默认吸附模式下健康字段的语义、全部参数校验规则、多槽丢帧时聚合过程
  噪声的方差、历史窗条件需要 `maximumFrames` 不先绑定、移植清单里情况 B 的历史窗
  按方案区分、`reset` 的时刻必须是初值角度的有效时刻、原型结论按数据集与噪声档
  分别给出。
